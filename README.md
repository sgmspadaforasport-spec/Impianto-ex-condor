# Impianto Sportivo Ex Condor – Venetico

Sito ufficiale per prenotazioni dell'impianto sportivo.

## Stato
Prima versione frontend. Prenotazioni attualmente in modalità demo; il prossimo passaggio è il collegamento a Supabase per disponibilità reale, stati in attesa/confermata e area amministratore.

## Funzioni
- Prenotazione Calcio a 5 e Bocce
- Slot da 60 minuti, 15:00–24:00
- Tornei
- Regolamento
- Contatti
- Responsive mobile
